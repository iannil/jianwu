# jianwu 独立产品与可靠交付

用户已批准：jianwu 不再服务 mouqin，成为独立产品；其余按项目评析建议实施。

## 产品边界

jianwu 是面向非虚构作者与知识整理者的本地优先 CLI 产品。核心价值是可审阅、可追溯的结构化图书创作。内部引擎服务本产品；不为 mouqin 提供公共 SDK，不以多租户/SaaS 为发布前置。历史官网与部署资产保留，当前产品文档撤下 mouqin SaaS 导流，不部署或迁移线上站点。

## 可靠性

批量展开使用有界并发，工作任务只生成结果，协调者依次写章节并合并同一份大纲。失败继续处理其他章，但最终返回非零错误；支持取消。文件写入采用同目录临时文件加 rename，避免截断现有 JSON/章节。跨 CLI 进程同时编辑同一本书暂不支持，明确记录限制。

验证阶段完整保留最终正文 claims。每个 claim 用 citation_ids 关联来源，复核不按数组下标猜测。缺失关联、缺失来源或读取失败产生未通过结论，旧数据可读取但必须重新展开才能补齐关联。文本白名单不能替代当前来源验证。改写后作废旧审阅与复核结果，重新提取正文 claims 和引用再复核。

## 计量与发布

Token 类型独立于引擎实现，书级累计记录 provider 报告的用量（重跑累加、失败响应已报告用量仍保留）。new 覆盖 intake/outline/scaffolding，expand 包括 --all，factcheck/revise 也记录。流式不应绕过计量；provider 未提供用量时明确为不完整，不伪造费用。status 展示累计；--tokens 只控制即时输出。

默认版本 0.3.6-dev；--version 与 version 子命令显示一致构建信息。release 脚本显式版本参数，支持纯本地 dry-run，校验工作区、测试和版本；不自动向远端推送。

## 验证

Go 1.25+，无新增运行时依赖。遵守现有表格驱动测试惯例。先补故障回归测试，再实现，再执行 go test -race ./...、go vet ./...、格式检查和 release dry-run。准备样书评估流程，人工质量/读者测试只报告实际观测，不以 mock 结果冒充。
