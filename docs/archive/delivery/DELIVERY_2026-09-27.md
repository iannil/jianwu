## 范围

采用 ADR 28：jianwu 为独立 CLI 产品，不再为 mouqin 提供内核。更新 README、领域上下文、功能/状态/路线图和入门指南；旧路线移入历史快照。官网资源保留且标明历史状态，无线上部署。

## 实现与回归

- 批量生成有界并发与集中落盘：覆盖多章成功、部分失败、超过并发上限的排队取消、Token 累计。
- 单文件原子替换，展开/修订普通 I/O 失败回滚：覆盖写入截断、rename 失败、正文成功后 outline/meta 保存失败。
- 完整 claims 与显式 citation_ids；缺失/重复/失效来源不会被跳过或错误配对；旧文本白名单不再授权通过。
- 修订后重建正文关联、清空旧审阅/verdict、恢复 draft；闭环测试覆盖展开、失败复核、修订、再次复核、人工审阅、定稿和导出。
- 已报告 LLM 用量累计、缺失报告提示；覆盖并发、失败响应、流式、重试/fallback、访谈失败恢复及大纲失败。
- new --force 重试保留先前累计用量，以会话导入检查点避免重复计数；连续失败恢复有回归测试。
- 工厂将配置模型绑定到 Chat/Stream/Embed；fallback 各自使用配置模型，显式请求仍可覆盖。
- 版本输出、本地发布脚本、源码指纹和校验和；发布保护测试覆盖脏工作区、版本参数、源码/索引/HEAD 变化。
- 整理原有格式差异，不引入新的运行时依赖。
