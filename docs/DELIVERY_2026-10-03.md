# 出版层交付记录（2026-10-03）

## 范围

按 [ADR 29](decisions/29-publishing-layer.md) 实现出版层第 1–3 步（开发版本 0.3.11，未打 tag）：

1. **publish / Release 模型**（`internal/release`，[计划](plans/2026-10-03-publish-release.md)）：发布硬门（全书 final + `meta.json` license 必填 + 版本未占用；未核验论断等警告披露不拦截并记入 manifest）；版本自动推导（结构变化升 major、内容修订升 minor）；`releases/<X.Y>/` 产出 manifest（内容 sha256）、provenance（模型/已报告用量/AI 披露/去重来源清单）、状态快照与章节副本，EPUB 经注入钩子装配 artifact；staging + Rename 原子落位。Meta 新增 `Author`/`License` 可选字段；MemStorage.Rename 补目录语义。
2. **EPUB3 导出**（`internal/export`，[计划](plans/2026-10-03-epub3-export.md)）：纯 Go（goldmark 唯一新依赖，零传递）。脚注按章编号、EPUB3 aside + ARIA 角色；每章"来源与核验"节由 Citations/Claims/Verdicts 生成（✓ 支持 / ✗ 未通过 / 未核验 / 无引用 四态）；正文原始 HTML 转义保 XHTML 良构；确定性构建（UUID 标识、`dcterms:modified` 取 `Meta.UpdatedAt`、固定 zip 时间戳与条目顺序）——同书籍状态字节相同，release artifact 与 `export --target epub` 产物一致（集成测试断言）。封面约定 `cover.png|jpg`。
3. **静态阅读站与 OPDS**（`internal/site`，[计划](plans/2026-10-03-static-site-opds.md)）：只读 releases/ 生成书架页、书页（colophon/目录/EPUB 下载带 sha256 摘要）、章节阅读页（与 EPUB 共用渲染器，来源核验节逐字一致，上一章/下一章导航）、`epub/` 下载物与 OPDS 1.x acquisition feed。确定性输出；损坏 release 跳过并报告；`site/` 为派生状态整体重建。

CLI 新命令 `publish`、`site`；serve 新端点 `POST /books/{slug}/publish`、`GET /books/{slug}/releases`、`POST /site/generate`；Web UI 发布入口、版本历史、EPUB 导出/下载、生成阅读站入口。实现时的一处设计细化已回注 ADR 29：阅读站从 releases/ 生成而非演进 hugo 导出。

## 实现与回归

- release 包：发布门四类拒绝 + 三类警告、版本推导（首版 1.0/增删章升 major/内容修订升 minor/`--version` 校验与回退拒绝/缺 manifest 拒绝）、manifest 哈希与落盘文件一致（读回校验）、同版本不可覆盖、staging 清理、MemStorage 路径。
- export 包：脚注语义（唯一 fnref id、noteref↔aside 链接、原始 HTML 转义）、核验四态映射（含 verdict 文本失配回退 citation id）、zip 结构（mimetype 首条 STORED）、全部 XML 良构（`encoding/xml` 解析）、封面接线、确定性两次构建字节相等。
- site 包：书架仅含已发布书（用 `release.Publish` 真实造数，非手摆目录）、章节页内容与导航、OPDS 良构与 acquisition 链接目标存在、无 artifact 书保留 alternate 链接、损坏 release 跳过、空工作区、两次生成字节一致、根页样式路径不越界。
- CLI/serve 集成：dry-run 不写盘、发布 job 失败可见、export 与 release artifact 字节一致、site job 全链路（publish→site→epub 下载）。

## 验证记录

测试环境：Go 1.25（darwin arm64）。

- `go test -race ./internal/...` 全部通过；`go vet ./...` 通过；`gofmt -l` 本轮文件无输出。
- `scripts/release.sh 0.3.11 --dry-run` 通过：完整测试、构建校验与 SHA256SUMS 生成；仅本地演练，未打 tag、未发布。
- `scripts/epubcheck.sh` 结构回退路径在真实导出产物上通过（本机无 Java epubcheck）。
- 真实二进制冒烟：`publish`（dry-run/发布/同版本拒绝）→ `export --target epub`（解包核对章节页脚注与来源核验节）→ `site`（书架/OPDS/章节页/下载物核对）。
