# jianwu 成为独立产品（2026-09-27）

## 决定

用户明确指定：jianwu 不再服务 mouqin，成为独立产品。此决定替代 ADR 27 中关于 mouqin 集成、单租户 MVP、多租户触发条件的后续路线。

jianwu 是本地优先的非虚构图书创作 CLI，面向作者、研究者和知识整理者。产品交付单位是一部可审阅、可追溯、可导出的图书。内部引擎与 Provider 为此服务；不承诺外部可导入的 Go SDK。

## 范围与取舍

- 当前优先级：数据可靠性 → 事实复核闭环 → 可核对的用量与发布 → 完整样书和真实读者评估。
- 删除 mouqin 前置、Web SaaS、多租户、分账和公共 SDK 的排期；未来功能由 jianwu 自身用户的具体需求决定。
- 保留 `internal/` 边界；不为假设中的独立 SaaS 仓库重排包结构。
- `website/`、历史部署脚本和旧 ADR 作为已有资产保留。它们不代表当前产品路线，不自动改动线上站点；独立产品域名与视觉品牌尚未指定。
- 保留旧数据读取能力。旧 claims 若无 citation_ids，不按位置猜测来源，也不靠文本白名单视为已验证；重新展开后补齐。
- 发布版本仍为 0.3.6-dev，待校验、提交、标签和正式发布后才称为已发布版本。

## 验收

并行展开不能丢失已完成章节；失败写入不能将旧审核结果附着到新正文；事实复核使用最终正文的 claims 与显式引用 ID；用量显示必须说明未报告部分；真实读者与样书质量没有观测结果时不得宣称通过。

当前实现与后续限制见 [项目状态](../PROJECT_STATUS.md)、[样书评估](../EVALUATION.md)。
